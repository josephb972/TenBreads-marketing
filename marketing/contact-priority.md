# Contact priority (prospects.csv `contact_priority`; 1 = contact first)

1. Named finance persona + published email (email draft)
2. Named finance persona, no email (LinkedIn note; fallback switchboard / IR / company secretary)
3. Named Ops / Supply Chain / F&B persona (LinkedIn; ask to be pointed to finance or procurement)
4. Named non-finance persona (CEO etc.) (LinkedIn; ask for finance/procurement lead)
5. No named contact (find Head of Procurement / Financial Controller / Ops Director on LinkedIn; company form or published generic email)

Rules: never guess or pattern-build an email; generic addresses only if published on the official site (obfuscated ones must be read in a browser). Within a tier, sort by `score`. Prospector sets both columns each run.
